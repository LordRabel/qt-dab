RTL-SDR Dongle (Hardware)
    ↓
    ├─ USB: Raw uint8_t IQ @ 2.048 MHz
    ↓
[dab_receiver.py]
    ├─ RTLSDRHandler.get_samples()
    ├─ Konvertierung: uint8 → float complex
    ├─ DC-Offset Removal
    ├─ FrequencyCorrector.correct()
    ↓
    ├─ Korrigierte IQ Samples (complex64)
    ↓
[ofdm_processor.py]
    ├─ OFDMProcessor.process_samples()
    ├─ Symbol Extraction (T_g überspringen)
    ├─ 2048-Point FFT
    ├─ OFDMDecoder.decode_symbol()
    ├─ Carrier Extraction (1536 Träger)
    ├─ DQPSK: fftBin = current × conj(prevPhase)
    ├─ Normierung / max_amplitude
    ↓
    ├─ Konstellationspunkte (1536 complex)
    ↓
[constellation_display.py]
    ├─ ConstellationDisplay.update_constellation()
    ├─ Log-Magnitude Transform (optional)
    ├─ SNR Estimation
    ├─ matplotlib scatter plot
    ↓
    ├─ Grafische Anzeige
    ↓
BILDSCHIRM: Konstellationsdiagramm

⚙️ DAB MODE I PARAMETER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Samplerate:   2.048 MHz     (SAMPLERATE)
FFT Size:     2048          (T_u - useful symbol)
Guard:        504 samples   (T_g - cyclic prefix)
Symbol:       2552 samples  (T_s = T_u + T_g)
Null Period:  2656 samples  (T_null)
Carriers:     1536          (aktive Träger)
Frame:        76 Symbole    (1 null + 75 data)
Modulation:   DQPSK         (Differential QPSK)

💡 KERN-ALGORITHMUS (DQPSK Demodulation)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# ofdm_processor.py, Zeile ~150
current = fft_output[carrier_idx]
prev_symbol = phase_reference[carrier_idx]

if abs(prev_symbol) > 1e-10:
    normalized_prev = prev_symbol / abs(prev_symbol)
    fft_bin = current * conj(normalized_prev)  # ← MAGIE!

conj_vector[carrier_idx] = fft_bin

# fft_bin ist der Konstellationspunkt!

Die Information steckt in der PHASENDIFFERENZ zwischen Symbolen!
